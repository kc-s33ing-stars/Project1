 # VGM Percussive Isolator
 This is a front-end interface for isolating percussion or instrumental tracks from VGM (video game music). Users can either upload a file or select from themed genres before isolating audio.
 
 ## Features
 
 - Upload a file or choose from one of eight genres
 - Audio preview of both the original and isolated tracks
 - Full-screen color transitions between steps
 - OK button styling reflects genre selection or file upload
 - Built with Vue 3 and hand-written CSS (no libraries or frameworks)
